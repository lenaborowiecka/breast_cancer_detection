# Installation

## Stable release

To install breast cancer detection, run this command in your terminal:

```sh
uv add breast_cancer_detection
```

Or if you prefer to use `pip`:

```sh
pip install breast_cancer_detection
```

## From source

The source files for breast cancer detection can be downloaded from the [Github repo](https://github.com/lenaborowiecka/breast_cancer_detection).

You can either clone the public repository:

```sh
git clone https://github.com/lenaborowiecka/breast_cancer_detection
```

Or download the [tarball](https://github.com/lenaborowiecka/breast_cancer_detection/tarball/main):

```sh
curl -OJL https://github.com/lenaborowiecka/breast_cancer_detection/tarball/main
```

Once you have a copy of the source, you can install it with:

```sh
cd breast_cancer_detection
uv sync
```
